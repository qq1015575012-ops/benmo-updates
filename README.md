# 本末工具箱 · 更新包

这个仓库只放发布包（zip），不含源码。

## 下载

- 最新版：[Releases](https://github.com/qq1015575012-ops/benmo-updates/releases/latest)
- 国内不挂梯子：在 Release 附件地址前面加 `https://gh-proxy.com/`，例如
  `https://gh-proxy.com/https://github.com/qq1015575012-ops/benmo-updates/releases/download/v1.1.1/benmo-1.1.1.zip`

下载后请核对 Release 说明里的 SHA256；对不上就是没下完，重下一次。
客户端「检查更新」会自动按 镜像 → GitHub → 官方 的顺序换源，并支持断点续传。
